## 2. 字号层级与对齐规范

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| L1 | `28px` | `bold` | 图表主标题 |
| L2 | `24px` | `bold` | 泳道左侧角色名（或分区大标题） |
| L3 | `19px` | `bold` | 编号步骤列标题 |
| L4 | `18px` | `regular` / `bold` | 主副标题（regular）；节点卡片标题（`17–18px bold`） |
| L5 | `16px` | `regular` | 泳道角色副说明；高可读卡片正文（标准 `14–16px`） |
| L6 | `15px` | `regular` | 步骤列副标题；信息容器正文 |
| L7 | `13px` | `regular` | **连线 Pill 边标签专用**（严禁用于卡片正文） |

- **对齐与内边距**：卡片内文字一律左对齐（`text-anchor="start"`），左内边距 `14px`，正文上下留白 `8–12px`；每张卡片保持 `1 行标题 + 2~4 条精炼 bullet`（`•` 前缀，单行中文 ≤ 18 字 / 英文 ≤ 42 字符）。
- **自然折行**：容器宽减去左右各 `12–20px` 作为文本框宽度，写入完整字符串让渲染器自然折行；以 **Noto Sans SC** 实测行数调整卡片高度（`NotoSansCJK-Regular.ttc` / `NotoSansCJK-Bold.ttc` face index `2`），**禁止**用拉丁字符系数估算硬换行，也禁止把同一句话拆成多个文本框。

## 3. 几何间距与防碰撞数值表

| 规则项 | 推荐数值 | 目的 |
|---|---|---|
| 标准任务卡尺寸 | 宽 `255px` × 自适应高（基准 `108–120px`），圆角 `rx=12` | 视觉方正、文字舒展 |
| 步骤列步距 | 约 `305–340px`（卡片水平净间距 `>= 80px`） | 居中悬浮宽 `65–110px` 的 Pill 标签不碰卡边 |
| 跨泳道卡片垂直净间距 | `>= 80px` | 高 `26–29px` 的 Pill 标签距上下卡片各留 `>= 25px` |
| 折线避让列分隔虚线 | 垂直线段坐标偏离竖虚线 `15–20px`（如虚线在 `x=575`，折线走 `x=555` 或 `x=595`） | 杜绝实线叠在虚线上 |
| 连线与箭头 | 正交折线 `sw=2`（强调回环 `sw=3`）；实心小三角箭头与线同色，落在目标卡片外边缘 | 防止斜线凌乱与箭头被卡片遮挡 |
| Pill 边标签 | 圆角 `rx=4`，高 `26–29px`，填充与描边严格匹配连线语义主题 | 视觉轻盈且语义一目了然 |
| 泳道左侧标签区 | 左边距 `25px`，文字 `x≈45`，首列卡片 `x>=215` | 角色说明与首列卡片互不拥挤 |

## 4. 常见失败反例对照（自检避坑）

| 常见错误 | 后果 | 正确做法 |
|---|---|---|
| 所有卡片文字统一用 `#1e2d42` / `#6b7280` | 泳道与语义区分感瞬间消失 | 严格跟随 4 套主题深色文字（`#5a3f12` / `#1a3353` / `#16433c` / `#7a1f1f`） |
| 给卡片加 `drop-shadow` 或渐变 | 产生浮起脏感，破坏扁平贴纸美学 | 零阴影、零渐变 |
| 画布拉成 `3:1` 过扁长条 | 节点稀疏、缩小后文字看不清 | 保持紧凑比例（约 `1.6:1 ~ 2.1:1`），适当换行或竖向布局 |
| 失败/不可逆终态仍用蓝色或灰色 | 读者一眼看不到风险与异常出口 | 统一使用第 4 主题红色 Crimson（`#fef0f0` / `#cf5659` / `#7a1f1f`） |
| 拆句成多个上下排列的文本框或硬塞 `\n` | 导入白板二次编辑时碎片错位重叠 | 单语义单元单文本框，按容器宽自动换行并自适应框高 |
| 强套泳道画状态机或时间轴 | 大片空白、语义拧巴 | 按 `diagram-archetypes.md` 选用分阶段状态图或独立时间轴版式 |
| 中文混入英文 FSD 图表 | 客户评审直接打回（P0 缺陷） | 100% 与正文语言一致，自检目标语种纯净度 |
