# fsd-diagram（FSD 图表绘制思路与白板美学规范）

将复杂业务旅程、系统管线、状态机与时间边界转化为结构克制、视觉统一、无遮挡溢出的高可读性图表。默认产出平台无关的标准 **SVG / PNG**（适用于 Markdown、Notion、Confluence、Word 等），并按需通过飞书适配器写入飞书云文档画板。

---

## 何时使用

- 消费 `fsd-writer` 生成的 `[VISUAL-PLACEHOLDER | TYPE: diagram]` 占位符并出图
- 绘制 / 重绘 / 美化 FSD 中的端到端 User Journey 泳道图、数据处理管线与异常重试分支图、生命周期状态迁移图、决策流与规则栏、多时间窗口图、实体关系图
- 用户要求“方块风格”“不要纯 Mermaid”“统一配色/美学”，或原图被评空旷、拥挤、字小、阴影重、配色割裂、语言混杂
- 局部修改已有飞书画板（换文案、增删分支、修复溢出与折行）

## 核心美学铁律（一页速查）

### 1. 4+1 语义配色体系（最关键）

**节点文字必须跟随所属主题的深色变体**，严禁所有卡片统一用 `#1e2d42` 或 `#6b7280`！

| 主题语义 | 泳道/面板底色 | 卡片填充 | 卡片描边 (`sw=1.6`) | 节点文字 | 对应连线色 | 边标签描边 |
|---|---|---|---|---|---|---|
| **暖色 Amber**（人工角色 / 等待 / 候选 / 降级 / 异常重试） | `#fffcf5` | `#fff6e7` | `#b29161`（虚线 `6 4` 表候选/可选/规则） | `#5a3f12` | `#9b7538` | `#dfd1b8` |
| **蓝色 Blue**（AI Agent / 核心逻辑 / 正常处理 / 决策节点） | `#f5f8fe` | `#edf4ff` | `#5c83bb`（实线） | `#1a3353` | `#53677e` | `#d0dbe7` |
| **绿色 Sage**（系统与数据 / 确认通过 / 正常产出 / 最终处置） | `#f1f8f6` | `#e9f6f2` | `#599687`（虚线 `6 4` 表滑动延展窗口） | `#16433c` | `#488577` | `#c3ddd6` |
| **红色 Crimson**（失败 / 拒绝 / 不可逆终态 / 排除红线） | —（卡片独立使用） | `#fef0f0` | `#cf5659`（实线） | `#7a1f1f` | `#cf5659` | `#e5b3b4` |
| **浅蓝灰 Slate**（辅助参考区 / 底部规则或不变式横幅） | `#f4f7fb` | `#ffffff`（内卡） | `#7799c2`（外框）/ `#b3cbe6`（内卡） | `#1b3b68` / `#52647a` | `#53677e` | `#d0dbe7` |

### 2. 形状、字号与语言一致性

- **零阴影、零渐变**：禁止 `filter` / `drop-shadow` / `pattern` / `clipPath` / `mask` / 渐变。
- **圆角方块卡片**：标准 `rx=12`，卡片高度按文字实际折行占地自适应（正文上下留白 `8–12px`，内容变短时同步收紧，不为对齐强留大段空白）。
- **少用菱形决策框**：优先用蓝色普通圆角卡 + 正交连线 + 语义 Pill 边标签表达分支。
- **字号层级**（同图同层级统一，禁止逐卡缩字号迁就旧框）：
  - 主标题 `28px bold #1e2d42`；主副标题 `18px regular #52647a`
  - 步骤列标题 `19px bold #285188`；列副标题 `15px regular #5c7899`
  - 泳道角色名 `24px bold`（跟泳道主题色）；角色副说明 `16px regular`
  - 节点标题 `17–18px bold`；节点正文 `14–16px regular`（`•` 项目符号，左对齐，左内边距 `14px`）
  - 连线 Pill 边标签 `13px regular`（仅用于连线标签，不用于卡片正文）
- **语言 100% 与目标文档一致**：英文 FSD 中的所有标题、卡片、连线标签必须全英文（CJK 字符为 0），词汇严格对齐正文术语表。

### 3. 构图、排版与防碰撞硬规则

- **画布比例**：禁止拉成 `3:1` 过扁长条；横向图按步骤列网格对齐（标准列宽约 `255px`，列间距约 `305px`），纵向决策流按阅读方向顺流向下，不蛇形折返。
- **单语义单元单文本框 + 自然折行**：同一标题、同一句正文或同一边标签只放一个文本框，严禁手动硬截拆句或拆成多行独立文本块；按实际字体度量（中文/混排用 **Noto Sans SC**）估算折行高度，超长时加高容器并顺移后续节点，绝不缩字号硬塞。
- **正交折线与避障**：
  - 全图仅用水平+垂直正交折线（无斜线、无曲线），实心小三角箭头停在目标卡片边缘，严禁伸入卡片内部。
  - **线型语义**：实线 = 主流程 / 同步流转；虚线 = 异步回调 / 人工重试 / 规则重评估回环 / 终态后手动路径。
  - **间距护栏**：卡片横向间距 `>= 80px`；跨泳道垂直卡片间距 `>= 80px`（使高 `26px` 的 Pill 标签距上下卡片各保留 `>= 25px` 安全间距）；横向跨列折线的垂直段必须偏离竖向列分隔虚线 `15–20px`，严禁实线压在虚线上。
- **分隔线**：泳道之间用清晰水平实线（`#d8e0e9`）；步骤列之间用贯穿竖向虚线（`stroke-dasharray="8 6"`，`#d8e0e9`）；禁止用一串短 `<rect>` 拼虚线。

## 标准制作与核验工作流

1. **解析需求与选型**：
   - 读取 `references/diagram-archetypes.md`，从 FSD 正文或 `[VISUAL-PLACEHOLDER | TYPE: diagram]` 提取“图要回答的核心问题”、参与角色/泳道、主路径节点、异常/终止分支、语言要求与术语词表。
   - **严禁擅自加戏**：User Journey 只画用户动作与系统支撑结果；系统逻辑图画输入、处理、判断与异常；美化过程不得凭空增加未经确认的业务规则或多余说明侧栏。
2. **设计几何与生成 SVG**：
   - 参照 `references/style-tokens.md` 分配 4+1 语义配色、计算文本自然折行高度与防碰撞连线坐标，生成干净、无阴影的独立 SVG。
3. **本地渲染与双层质检**：
   - 将 SVG 渲染为 PNG 预览图，并检查溢出、节点碰撞、文字遮挡与语言纯净度（若环境有 `@larksuite/whiteboard-cli`，可加跑 `--check` 辅助校验）。
   - **必须目视检查预览图**：工具警告为 0 不等于视觉合格，逐框核对底部留白、标题间距、箭头落点、Pill 标签避障、折线与列虚线错位及整体纵横比。
4. **交付或发布到目标平台**：
   - **通用 Markdown / Notion / Word**：直接交付 SVG / 高清 PNG，按 Placeholder 图注回填。
   - **飞书云文档画板**：按 `references/feishu-whiteboard.md` 与 `references/board-roundtrip.md` 执行备份、局部增删（或已授权的整板写入），并在写入后导出 `raw` 与真实 `preview` 做二次目视核验。
